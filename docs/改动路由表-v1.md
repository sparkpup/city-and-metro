# 改动路由表 v1

> **副本**，正本在工作区 `模拟地铁游戏/docs/改动路由表-v1.md`；本文件供 `scripts/find.mjs` 检索，改内容请两处同步。

用法：查本表 → 只读「必读文件」→ 用「定位锚点」grep 出章节首行 → 从该行读 80–200 行，**不要整文件读**。
表外场景查 `docs/架构分层与代码地图-v1.md` §2；检索用 `node scripts/find.mjs <关键词>`（默认跳过 `js/content/`）。
路径均相对 `reference/city-and-metro/`；行号不写进本表（会漂移），锚点用关键字。

| 我想改什么 | 必读文件（≤2） | 定位锚点（可直接 grep 的关键字） | 不要读 |
|---|---|---|---|
| 调经济数值（GDP/增长/利率） | `config.js`、`macro.js` | `growth: {`（人口曲线）、`// ===== 参数`、`// ===== 采样与年度结算` | `render.js`、`sim.js` |
| 改票价与财政科目 | `config.js`、`economy.js` | `fareDefault`、`// ===== 资金流水`、`建设支出` | `city.js` |
| 改线路规则（半径/坡度/站台） | `config.js`、`metro.js` | `minRadiusM`、`maxGrade`、`// ---- 线路形态`、`// ---- 选址检查` | `sim.js`、`render.js` |
| 改站点/轨道建造成本 | `config.js`、`metro.js` | `cost: {`、`// ---- 草案差异、费用与冲突` | `economy.js` |
| 改地图渲染样式（配色/建筑/图层） | `render.js` | `// ---- 城市风貌`、`// ---- 分析图层`、`// ---- 地铁绘制` | `ui.js`、`geo_*.js` |
| 改界面某个面板 | `pages.js`、`ui.js` | `page_<kind> = function`、`// ===== 右侧面板（页面栈）` | `render.js`、`sim.js` |
| 加一座新城市 | `maps.js`、`data_<id>.js` | `CFG_KEYS`、`MAP_LIST`、`difficulty` | `geo_*.js`（只读头部 proj/names） |
| 改任务线（目标/奖励） | `economy.js`、`pages.js` | `// ===== 任务`、`page_tasks` | `sim.js` |
| 改存档格式/迁移 | `save.js`、`config.js` | `SAVE_VERSION`、`onupgradeneeded`、`mp.migrate` | `data_*.js` |
| 改预测性能（Worker/耗时） | `simclient.js`、`sim.js` | `CORE_RE`、`// ---- 建设前预测`、`useWorker` | `geo_*.js`、`render.js` |

**「不要读」的实质**：静态结构已集中在 `js/content/`（16 个文件）——其中 `js/content/geo_*.js` 7 个 = 6.14 MB = 全仓 80.7% 体积，
是 OSM 构建产物（头部有 `@generated`），只允许 `head -c 400` 取 `proj`/`names`，层结构看 `js/geo.js` 的 `KEYS`；
`js/content/data_*.js` 与 `js/content/config.js` 只在「加城市 / 改城市内容 / 调数值」时读。业务代码全在 `js/` 顶层，可放心搜。

改完的验证只用一条：`node tests/headless/city.mjs --check`（16 行 PASS，输出 < 1 KB）。`--smoke` 约 8 分钟且重写基线，只在显式更新基线时用。
