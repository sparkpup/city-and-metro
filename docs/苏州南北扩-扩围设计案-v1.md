   - 分层对比（合并前→后）：admin `44 → 166`、roads `11463 → 51534`、places `561 → 2275`、water面 `5308`、streets `30843`、rail `820`、parks `945`、woods `934`。

## 5. 注意事项 / 待优化

- **建局耗时 ~19.7s**（headless，无浏览器渲染）：roads 由 11463 → 51534（4.5×）、格数 2.2× 所致，符合合并影响分析 §9 预期（admin fill O(要素×N)≈3.7×、OD 展开 4.8×）。真实浏览器加载 3.4 MB `geo_sz.js` + 解码亦偏重。建议后续：① `city.js` admin `fillCells` 改按要素 bbox 局部填充；② `render.js` parks/reserves/woods/water/rail 五层接入 `Geo.buckets`（待办 #9）。
- `defaultRegion`（outer）仍 open 2013，覆盖太仓（东界外）、长江以北等未显式区域。
- 设计案坐标里的 ✔/○ 核验标记已在落码时去除；常熟/张家港中心人口为估算，后续可用 OSM `places`（2275 条）与真实统计微调。
